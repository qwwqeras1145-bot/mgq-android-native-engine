============================================================
  mgq 安装助手
============================================================

  双击运行：  一键送到手机.bat

  它会自动完成：
    1. 检查 adb 和 Winlator APK
    2. 等手机连上（USB 调试）
    3. 检查手机剩余空间够不够
    4. 安装 Winlator
    5. 把 D:\mgq 推进手机
    6. 核对结果

  跑完之后，手机上只剩下「建容器 + 做桌面图标」两步（约 2 分钟），
  脚本结束时会打印具体怎么做。

------------------------------------------------------------
  运行前要做的
------------------------------------------------------------

  1. 手机插上数据线
  2. 手机打开「USB 调试」：
       设置 -> 关于手机 -> 连点「版本号」7 次
       设置 -> 系统 -> 开发者选项 -> USB 调试 -> 打开
  3. 插上后手机上如果弹「允许 USB 调试吗？」-> 勾选「始终允许」-> 确定

  手机空间至少留 8.5 GB。


------------------------------------------------------------
  这个文件夹里有什么
------------------------------------------------------------

  一键送到手机.bat        双击这个

  一键送到手机.ps1        实际干活的脚本

  Winlator_11.2.apk       Winlator 安装包（150 MB）
                          来源：https://github.com/brunodev85/winlator/releases

  platform-tools\         adb 工具（Google 官方）
  platform-tools.zip      来源：https://dl.google.com/android/repository/platform-tools-latest-windows.zip


------------------------------------------------------------
  为什么要用 adb 而不是手动拖文件
------------------------------------------------------------

  手动拖 4.26 GB 到手机上有几个坑：
    - 中途断了要重来，不知道传到哪了
    - 文件夹名容易被输入法打成中文，导致游戏跑不起来
    - 传完不知道有没有传全

  这个脚本用 adb 做，能显示进度、能核对大小和关键文件、
  并且保证手机上的文件夹名一定是 mgq（纯英文）。


------------------------------------------------------------
  出问题
------------------------------------------------------------

  「等了 3 分钟仍未等到设备」
      - 换一根数据线（有些线只能充电）
      - 确认手机上点了「允许 USB 调试」
      - 确认开发者选项里的 USB 调试已打开

  「空间不够」
      - 手机上删点东西，至少留 8.5 GB

  「安装失败」
      - 改成手动：把 Winlator_11.2.apk 拷到手机，点它安装

  脚本中途中断
      - 直接重新双击运行，已经传过的部分会跳过，不会重复传
