   手机上玩「勇者大战魔物娘三章」—— 操作单
   照着做就行，不用懂技术
══════════════════════════════════════════════════════════════

【为什么要这么做】
  这个游戏是 NScripter 引擎，做不出安卓 APK（技术上不存在这条路）。
  但安卓上有个软件叫 Winlator，能直接跑 Windows 程序。
  装它 + 把游戏拷过去 = 手机上点图标就能玩。
  效果和你装了个 APK 完全一样。


──────────────────────────────────────────────────────────────
 ★ 省事办法：双击一个文件，第 1、2 步全自动 ★
──────────────────────────────────────────────────────────────

  打开 D:\mgq-安装助手\ ，双击：  一键送到手机.bat

  它会自动帮你：
    - 等手机连上
    - 检查手机空间够不够
    - 装好 Winlator
    - 把 4.26 GB 游戏推过去
    - 传完核对有没有传全

  你只需要先把手机插上数据线、打开 USB 调试。

  跑完之后，只剩「建容器 + 做桌面图标」两步要手动
  （就是下面的第 3、4、5 步，约 2 分钟）。

  想手动做也行，下面是完整步骤。


──────────────────────────────────────────────────────────────
 第 1 步：把游戏拷到手机
──────────────────────────────────────────────────────────────

  电脑上我已经建好了 D:\mgq（就是游戏的快捷入口，内容一样）

  ● 推荐做法：数据线

    1. 用数据线把手机连到电脑
    2. 手机上会弹出提示 → 选「传输文件」或「MTP」
       （没有弹窗的话，下拉通知栏找 USB 相关选项）
    3. 电脑上打开「此电脑」，能看到你的手机
    4. 进去后找「内部存储」→「Download」文件夹
    5. 在 Download 里新建一个文件夹，名字必须是：  mgq
       ★ 必须是小写英文，不能中文，这点最重要 ★
    6. 打开电脑上的 D:\mgq，全选里面所有文件，复制
    7. 粘贴到手机 Download\mgq 里
    8. 等待（4.26 GB）
       USB3.0 约 3 分钟 / USB2.0 约 20 分钟

    完成后手机上的路径应该是：
      Download\mgq\勇者大战魔物娘三章完全汉化版.exe
      Download\mgq\nscript.dat
      Download\mgq\arc.nsa
      ... 等等

  ● 手机空间要留够
    游戏 4.26 GB，还要留 2 GB 给 Winlator，建议空出 8.5 GB 以上

  ● 有读卡器的话，用 SD 卡拷更快


──────────────────────────────────────────────────────────────
 第 2 步：手机装 Winlator
──────────────────────────────────────────────────────────────

  1. 手机浏览器打开：
     https://github.com/brunodev85/winlator/releases

  2. 下载最新那个 Winlator_x.x.apk
     ★ 只从这个官方页面下，别从第三方网站下 ★

  3. 点击安装，如果提示「未知来源」，选允许

  4. 打开 Winlator，三个权限全部点「允许」
     （存储读写、音频）

  5. 第一次打开它会解压系统文件，显示「Installing system files」
     ★ 等 30～90 秒，千万别关掉 ★


──────────────────────────────────────────────────────────────
 第 3 步：建一个「容器」
──────────────────────────────────────────────────────────────

  容器 = 一个虚拟的 Windows 环境

  点右上角「+」新建，按下面填：

    项目                     填什么
    ───────────────────────────────────────────
    Screen Size（分辨率）     800x600
    Graphics Driver          有 Adreno 选 Turnip
                             其他选 VirGL
    DX Wrapper               ★ CNC DDraw ★ ← 最关键
    Box86/Box64 Preset       Compatibility
    Windows Version          Windows XP
    Audio Driver             ALSA

  ★ DX Wrapper 一定要选 CNC DDraw
    这个游戏用的老式 DirectDraw 绘图，选 DXVK 会黑屏

  然后到容器设置里的「Drives」（驱动器），添加：
    盘符 D:   映射到   /sdcard/Download


──────────────────────────────────────────────────────────────
 第 4 步：运行游戏
──────────────────────────────────────────────────────────────

  1. 保存容器，回到主界面
  2. 点进容器，会看到一个像 Windows 的资源管理器
  3. 找到 D:\mgq\
  4. 双击「勇者大战魔物娘三章完全汉化版.exe」

  第一次启动会黑屏 10～30 秒（Wine 在初始化），别急着关


──────────────────────────────────────────────────────────────
 第 5 步：★ 弄个桌面图标（这就是你要的效果）★
──────────────────────────────────────────────────────────────

  1. 在容器里找到那个 .exe
  2. 两个手指同时点一下它（触屏）
     （接鼠标的话：左键单击选中，再按 Ctrl+左键单击）
  3. 弹出菜单选「Create Shortcut」
  4. 回到 Winlator 主界面，找到刚建的快捷方式
  5. 点它右边的「⋮」→ 选「Add to Home Screen」

  ★ 做完这步，安卓桌面上就有图标了，点一下直接进游戏 ★

  还想要更好看：
    - 换成游戏封面图标
    - 改名字（重命名快捷方式就行）


──────────────────────────────────────────────────────────────
 出问题怎么办
──────────────────────────────────────────────────────────────

  ■ 双击 exe 没反应 / 闪退
    → 检查 DX Wrapper 是不是 CNC DDraw
    → 检查 Windows Version 是不是 XP
    → 检查手机上的文件夹名是不是纯英文 mgq

  ■ 文字全是方框 / 乱码
    → 容器设置 → Environment Variables
      加一条： LANG = zh_CN.GBK

  ■ 没声音
    → 容器设置里 Audio Driver 改成 ALSA
    → 检查手机是不是静音了

  ■ 画面卡
    → Box86/Box64 Preset 改成 Performance
    → 分辨率降到 640x480

  ■ 存档存不上
    → 手机上的 mgq 文件夹权限问题
    → 设置里给 Winlator 完全的文件访问权限

  ■ 桌面图标点开闪一下就没
    → 把 exe 文件名改成英文（比如 mgq.exe）
      中文文件名在 Wine 里偶尔会出问题
      这是改名字，不是改游戏内容，随时能改回来

 小提示
──────────────────────────────────────────────────────────────

    这是正常的，画面最清晰
