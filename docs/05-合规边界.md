# 05 · 合规边界

本文件说明本项目的**能做什么 / 不能做什么**，以及为什么画这条线。

---

## 一句话原则

> **让软件在我自己的设备上运行** = 使用（合法）
> **把软件复制给别人** = 发行（需要授权）

本仓库只做前者。

---

## ✅ 本仓库做的事

| 事项 | 说明 |
|---|---|
| 引擎识别方法论 | 从目录结构判断游戏引擎的通用方法 |
| 格式逆向 | `nscript.dat` 编码与 `.nsa` 归档的格式规范（描述格式，不含内容） |
| 引擎实现 | 用 Kotlin 重写的 NScripter 解释器，**不含任何游戏资源** |
| 分析工具 | `tools/analyze_port.py`，只读扫描，不改任何游戏文件 |
| 操作指南 | 如何把自己拥有的游戏数据交给本应用读取 |
| 失败路线记录 | 记录被推翻的旧方案，避免重复踩坑 |

**这些内容不包含任何第三方游戏的知识产权成果。**

---

## ❌ 本仓库不做的事

| 事项 | 原因 |
|---|---|
| 上传游戏本体（`.exe` / `.nsa` / 素材） | 侵权 |
| 上传汉化补丁 | 汉化补丁的法律地位因法域而异，整合版明确侵权 |
| 提供游戏下载链接 | 帮助侵权 |
| 把游戏重打包成 APK 并分发 | 复制 + 发行 + 演绎 |
| 存储、转发任何访问凭据 | 安全底线 |

---

## 为什么这条线不能越

### 测试目标的授权状态

项目勘察时读取游戏目录内的说明文件：

> **5 本游戏汉化仅仅为了日语学习交流 请在下载24小时内自行删除 如果喜欢本游戏请支持正版。**

这句话本身就是证据：

- 要求下载者 **24 小时内删除** → 承认这是未经授权的复制
- 请 **支持正版** → 承认这不是正版

原始游戏是日本 **Torotoro Resistance** 的商业作品，在 DLsite 等平台正规销售。

### "我只是汉化" 的常见误解

| 形态 | 法律评价 |
|---|---|
| 纯翻译文本补丁（用户自备正版） | 各地不一，日本有多起刑事判例 |
| **整合版**（本体 + 汉化 + 破解） | **明确侵权** |
| 上架商店 / 公开仓库分发 | 加重情节 |

测试目标是**整合版**：4.26 GB 里包含完整游戏资源。

### 上传到 GitHub 的实际后果

1. **DMCA 下架** —— 无需事先通知，仓库直接消失
2. **账号标记** —— 重复侵权导致封号，你其他仓库一起受影响
3. **存储滥用判定** —— 4 GB 仓库会触发 GitHub 的滥用检测
4. **法定赔偿** —— 权利人可主张，中日美均有先例

> GitHub 的 Acceptable Use Policies 明确禁止将平台用于侵犯他人知识产权的分发。

## 关于访问凭据

本项目在开发过程中涉及 GitHub 推送，这里记录几条硬规则：

### 规则

1. **凭据绝不写入仓库**
   不写进代码、不写进配置、不写进文档、不写进提交历史。

2. **凭据只通过环境变量传入**
   ```bash
   export GITHUB_TOKEN="..."     # 或使用 git credential manager
   ```

3. **绝不回显**
   命令输出、日志、错误信息里都不应出现明文。

4. **用后轮换**
   任何在聊天、邮件、截图、工单中出现过的 Token，
   都应视为已泄露并立即吊销重建。

### 为什么强调这条

一个带 `repo` + `delete_repo` 权限的 GitHub Token 泄露，
等于**账号被完全接管**——攻击者可以：

- 读取你的所有私有仓库（包括其中的密钥）
- 向你的仓库注入恶意代码
- **删光你所有仓库**
- 以你的身份向他人仓库提 PR

### 本项目的做法

`tools/` 下的所有脚本：

- ❌ 不接收 Token 参数
- ❌ 不读取 Token 环境变量
- ❌ 不发起任何网络请求
- ✅ 只做本地文件系统扫描

**这是刻意的设计。**

## 如果你想要一个合法的安卓版

| 愿望 | 合法路径 |
|---|---|
| 手机上玩这个游戏 | 安装本引擎 APK，让它读取**你自己拥有**的游戏数据（[移植过程](07-移植过程全记录.md)） |
| 汉化被官方采纳 | 联系版权方提交翻译 |
| 做同类游戏 | 用 Ren'Py / Godot 从零开发自己的作品 |
| 做引擎工具 | 为**开源**引擎（Ren'Py、KiriKiri 等）写工具 |
